# QVAC owns semantic extraction

Accepted during grill-with-docs round 7 (Q32). QVAC converts free-form, potentially multi-equipment narratives into candidate atomic scoped claims and ambiguity candidates, including subject attachment, source, certainty, scopes, and supporting excerpts; it also phrases the one clarification selected by application rules. Deterministic code validates structure, prioritizes questions, persists data, protects lifecycle/concurrency, presents reconciliation, and calculates views, but must not contain a hidden regex, keyword, or hard-coded demonstration path that replaces QVAC's semantic transformation.

Manual structured entry remains measured failure recovery rather than QVAC success. This boundary makes local QVAC material to the product at the cost of accepting measured model errors and a mandatory draft-review step; E2 and E7, offline execution evidence, and the live primary demo determine whether that contribution is useful.
